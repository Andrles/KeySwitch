# KeySwitch settings

Mode: Operate. Native macOS AppKit settings, not a marketing page.

Direction approved by the user: light, modern, simple enough for a beginner.
Redesign replaces the purple gradient and glossy icon; retains KeySwitch name,
RU/EN functionality, permission boundary and native keyboard navigation.

Design dials: DESIGN_VARIANCE 3, MOTION_INTENSITY 2, VISUAL_DENSITY 3.
Use native SF typography and SF Symbols. Neutral semantic surfaces; macOS accent
for selection and actions. Semantic warning/success colors only for real status.
12-point group radii, no group shadows, 24-point content margins and 16-point
vertical group spacing. Native sidebar material handles system transparency.
System, light and dark themes apply to the whole window.

Main screen: current state, correction toggle, a safe local example, double-Shift
help and sound. Launch and icon visibility live in “Вид и запуск”. Menu-bar-only
presentation is the default, including while settings are visible; optional Dock
presence follows a persistent preference. Closing hides the window, not the app.

Copy names user outcomes: “Опечатки”, “Не исправлять”, “Доступ macOS”. Avoid
monitoring/engine jargon, decorative metrics and repeated feature summaries.
The app identity uses two flat language keys A/Я with a native switching symbol;
the menu bar uses a small template keyboard symbol instead of rotating letters.
