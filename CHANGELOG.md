# История изменений

## 3.5.1 — 2026-10-26

- Компактная стеклянная панель в строке меню: статус, общая пауза, правило текущего приложения и кнопка «Открыть приложение». Служебные действия доступны в основном окне.
- Переключатели активны сразу после первого клика по значку. Длинные названия приложений переносятся и не расширяют панель.
- Установка через терминал определяет стабильный релиз без GitHub API и его анонимного лимита запросов. Ошибка загрузки останавливает установку.
- PKG заменяет прежнюю копию в `/Applications/KeySwitch.app`. Дубликаты в `/Applications` удаляются только после проверки подписи новой копии; настройки и посторонние приложения сохраняются.
- Подпись приложения ad-hoc; пакет не подписан Developer ID и не нотариализован.

## 3.5.0 — 2026-10-25

- Полное слово проверяется перед автоматической заменой во всех поддерживаемых полях. Если границу или исходный текст подтвердить нельзя, замена пропускается.
- Восстанавливаются буквы на клавишах знаков в смешанной раскладке: `[орошо → хорошо`, `,абушка → бабушка`. Используются точные локальные словарные совпадения, внешняя пунктуация сохраняется.
- Улучшены подсказки для типичных опечаток. При неоднозначных системных кандидатах приложение воздерживается от предложения. Для проверенного малого списка опечаток доступна подсказка через другую раскладку, например `ghtdtn → привет`; такая замена требует подтверждения.
- Общий переключатель переименован в «Автоисправления», область паузы объяснена. Добавлены видимая подпись автоматической проверки обновлений и кнопка повторного запуска после сбоя. Раздел «Правила приложений» объясняет полное и частичное отключение.
- Удаление правила из словаря можно отменить в течение 15 секунд. Отмена сохраняет последующие изменения и не перезаписывает новое правило с тем же ключом.
- Расширены проверки длинных подсказок, состояний панели и действий словаря. Стеклянный стиль и положение подсказки справа сверху сохранены.
- Физически подтверждены обычная и смешанная раскладка, быстрый ввод, пунктуация и двойной Shift в TextEdit. В адресной строке Safari подтверждено `lbhtrnjh` + пробел + клавиша F → «директор а». Подробности и ограничения: `IMPLEMENTATION_AUDIT_2026-10-21.md`.
- Приложение имеет локальную ad-hoc подпись; установщик не подписан Developer ID и не нотариализован. Полное обновление на отдельном Mac и физический запуск на Intel не проверены.

## 3.4.1 — 2026-10-20

- Восстанавливается смешанная русско-английская раскладка внутри слова: например, `ktв → лев`. Используется только точный однозначный словарный вариант.
- В адресной строке Safari восстанавливается целое слово после временной недоступности поля. Распознанный обрывок отдельно не заменяется; ссылки, адреса и технические префиксы не обрезаются ради исправления.
- При неподтверждённой ручной AX-замене курсор возвращается на место, только если исходный текст и поле не изменились. Следующая клавиша не должна удалять оставленное выделение.
- В автономный словарь добавлены «лев» и «директор».
- Добавлены изолированный WebKit-стенд, регрессии восстановления слова и отключённая по умолчанию диагностика без произвольного текста ввода.
- Физической клавиатурой подтверждены смешанное слово, последовательность `привет ЛЕВ`, замена `lbhtrnjh → директор` в собственном WebKit-поле и в верхней адресной строке Safari. Это не гарантия для всех редакторов; ограничения остаются в отчёте выпуска.

## 3.4.0 — 2026-10-17

- Лёгкий нативный интерфейс: системное размытие главного окна и подсказки, переключатели NSSwitch, понятные названия разделов. При уменьшении прозрачности или повышении контраста macOS используется непрозрачный фон.
- Подсказка стала компактнее: ширина 380 пунктов, перенос длинных слов, действия «Заменить», «Пропустить», «Не предлагать».
- Улучшены распознавание имён, обработка регистра, краевых знаков и многоточий. Добавлены собственные словарные дополнения; системный словарь восстанавливается после временного отказа.
- Смена языка ввода проверяется по фактическому результату macOS. Если текст заменён, но язык не переключился, приложение сообщает об этом и сохраняет отмену.
- В TextEdit физической клавиатурой подтверждены исправление слов и имени, сохранение запятой, язык следующей клавиши, применение/отмена двойным Shift, кнопки подсказки, отмена исключения и закрытие подсказки при переходе в поиск.
- Установочные сценарии проверены в изолированных условиях. Полное обновление рабочего Mac ещё не проверено. Сборка ad-hoc; пакет не подписан Developer ID и не нотариализован. Подробности: `RUNTIME_VALIDATION_2026-10-17.md`, `CARAMBA_FIXES_2026-10-16.md`.

## 3.3.2 — 2026-10-12

- Подсказка стала читаемее в светлой и тёмной теме. Основные действия: «Заменить» и «Пропустить»; постоянное исключение слова объясняется и допускает отмену.
- Принятые подсказки и отмена используют проверяемую запись выделенного текста через Accessibility. Успех показывается только после чтения результата; неподдерживаемое поле не получает клавиатурного удаления.
- Исправлена подсказка «превет → пресет»: теперь предлагается «привет» с сохранением начальной заглавной буквы и пунктуации. Эта неоднозначная опечатка не заменяется автоматически.
- Tab не создаёт подсказку для прежнего поля; отложенный показ проверяет актуальный контекст. Esc закрывает активную подсказку, а без неё передаётся редактору.
- Подсказка выбирает монитор редактора по доступным координатам поля. Несколько физических мониторов ещё не проверены.
- Правка и удаление строки словаря доступны только после выбора. Названия действий и описание режима проверки приведены в соответствие с поведением.
- В TextEdit физическими клавишами подтверждены кнопка замены, начальная заглавная буква, применение и отмена двойным Shift. Расширенный языковой прогон не выявил новых регрессий; прежние пропуски автопереключения сохранены в отчёте.
- PKG/ZIP и запуск упакованного приложения проверены. Полная установка 3.3.2 на рабочий Mac ещё не проверена. Подпись приложения ad-hoc, пакет не подписан и не нотариализован. Подробности: `POPUP_IMPROVEMENTS_2026-10-12.md`.

## 3.3.0 — локальная проверочная сборка, 2026-10-05

- Правила отдельных приложений: независимое управление автоматической раскладкой, орфографией и сокращениями. Старые полные исключения сохранены.
- Локальные сокращения в готовые фразы: отдельное включение, запуск только после пробела, сохранение текущей раскладки и проверяемая отмена.
- Фразы включены в импорт/экспорт словаря; старые файлы читаются. Ограничены длина фразы и размер событий ввода.
- Физическими клавишами подтверждены разворачивание фразы, возврат сокращения и смена раскладки выделения. Локальные PKG/ZIP проверены; установка на Mac и GitHub Release пока не выполнены.

## 3.2.1 — локальная проверочная сборка, 2026-10-05

- Устранены три дефекта словаря: потеря слова при невалидной правке, несовместимый собственный экспорт и сохранение неподдерживаемых пар.
- «Мой словарь»: поиск и редактирование по строкам, явное сохранение, отмена ввода и сообщения о результате.
- «Ручные действия»: отдельный раздел, запись собственных сочетаний, защита известных системных команд и конфликтов внутри KeySwitch.
- Отказы ручных операций объясняются текстом без переключения фокуса редактора.
- Простой режим двойного Shift по умолчанию для новых настроек; существующий явный выбор сохраняется.

### Добавлено

- полностью обновлённое окно настроек с боковой навигацией и лёгким
  интерфейсом в стиле macOS;
- системная, светлая и тёмная темы; на macOS 26 используется системный

  доступ используется только для необязательной проверки версии.

## 3.1.0

- Simplify settings with neutral native surfaces, readable captions and plain labels.
- Focus the main screen on layout correction and a safe local example.
- Replace the glossy app icon with flat A/Я keys and use a native keyboard symbol
  in the menu bar; remove rotating letter animations.

## 3.1.1

- Protect correct vocabulary, proper names, technical terms, abbreviations and identifiers before layout conversion.
- Remove approximate name rewriting and preserve case when converting brands. Restrict automatic model recognition to established model families.
- Use curated common typo rules for automatic spelling; keep ambiguous spell-check guesses as explicit suggestions.
- Cache case-neutral guesses and apply capitalization per request, including ALL CAPS.
- Share punctuation parsing between spelling and layout; fix spelling inside quotes/brackets and recognize Tab as a word boundary.
- Skip automatic edits at address/path/code separators, protect drive prefixes and long Unicode event buffers.
- Add offline vocabulary, deterministic stress audit and strict regressions for the reproduced defects.

- Add a suggestion Apply button, configurable individual manual shortcuts, and an optional layout-only double Shift mode.

- Consume configured manual shortcuts even when editing fails, and perform Accessibility edits outside the event-tap callback. Cancel delayed commands when input or the target changes. Physical TextEdit tests confirmed layout, uppercase and lowercase conversion without extra control characters.
