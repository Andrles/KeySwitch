# KeySwitch 2.0.2

Первый подготовленный публичный релиз KeySwitch — нативного офлайн-переключателя русской и английской раскладок для macOS.

## Основные возможности

- автоматическое исправление текста, набранного в неверной раскладке;
- русский и английский системные словари macOS;
- проверка орфографии и необязательное автоисправление;
- ручная конвертация текущего слова двойным нажатием Shift;
- исключения для отдельных приложений;
- управление из строки меню;
- универсальная сборка для Apple Silicon и Intel.

## Установка

Скачайте `KeySwitch-2.0.2.pkg` и следуйте инструкциям установщика. После первого запуска предоставьте KeySwitch доступ в разделе:

**Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.

Сборка не нотаризована Apple, поэтому macOS может показать дополнительное предупреждение безопасности.
