# Layout and spelling stress audit

Audit date: 2026-10-03. Seed: 20261003. This harness compiles the application's actual LanguageEngine, SystemDictionary and KeyboardTokenClassifier; it does not change them.

Generate cases with `python3 Tests/StressAudit/generate.py`, then run `./scripts/stress-audit.sh`. If NSSpellChecker reports a sandbox/XPC error, that run is NOT the system-dictionary result. Run the compiled `build/stress-audit/audit` with `KEYSWITCH_DISABLE_SYSTEM_DICTIONARY=0` in an authorized local environment that can reach the macOS spell service. Confirm `system en hello=true ru мир=true`.

The first argument is a result label, the second a cases JSON, the third an output JSON. For fresh-cache order tests run lower/title/upper and upper/title/lower forms of the same misspelling in separate processes.

`keep` and `spell` compare preservation of supplied correct/technical/name tokens. Some short identifiers and transliterations are intentionally outside common dictionaries; inspect mismatches rather than treating every row as a distinct defect. `layout` compares exact restoration of independently encoded intended tokens; canonical brand formatting, ambiguities between languages and foreign characters also produce mismatches. `roundtrip` checks the invertibility of mapped key characters, not language recognition. `keep-exploratory` is a deterministic sample from macOS web2, which includes archaic words. `robust` exercises long inputs without claiming language accuracy. `probe-spell` and `stream-auto-probe` are observations with no asserted intended correction, so their `passed` value is not a test failure.

`stream` and `stream-auto-keep` model the inspected monitor's token accumulation, navigation policy, 64-character limit, layout-first ordering and trailing punctuation handling, using production classifier and engine. They assume suffix verification and text replacement succeed. They do not instantiate KeyboardMonitor and do not test actual CGEvent delivery, AX, caret timing, input source selection or specific editors. Any monitor change requires updating this model or replacing it with a directly testable production decision layer.

`layouts.swift` reads enabled keyboard layout tables with Carbon. It never switches input sources. Platform translation output requires independent confirmation before being classified as a product defect.

The audit records mismatches for analysis and deliberately exits successfully after recording them; it is not a release gate. The project's baseline tests and the findings in LAYOUT_STRESS_REPORT.md remain separate readiness evidence.

## Expanded mixed-layout audit (2026-10-20)

After generating the baseline corpus, run `python3 Tests/StressAudit/generate_scenarios.py`. It writes `build/stress-audit/scenarios.json`. Reuse the binary compiled by `scripts/stress-audit.sh`:

```sh
KEYSWITCH_DISABLE_SYSTEM_DICTIONARY=1 build/stress-audit/audit scenarios-fallback build/stress-audit/scenarios.json build/stress-audit/scenarios-fallback.json
KEYSWITCH_DISABLE_SYSTEM_DICTIONARY=0 build/stress-audit/audit scenarios-system build/stress-audit/scenarios.json build/stress-audit/scenarios-system.json
```

`recover-layout` passes optional `typedSuffix` to the production `KeyboardTokenRecovery`, then applies the production language decision to the recovered token. Expected output is the entire fixture document. This tests bounded UTF-16 reads and stale-buffer rejection, not live AX, focus, event delivery or input-source timing. Corpus targets include intentionally protected technical names; inspect unchanged mismatches before classifying them as defects.

For separate-process engine latency, compile `Tests/LatencyAudit/main.swift` with `SystemDictionary.swift`, `LocalLexicon.swift`, and `LanguageEngine.swift`, using `swiftc -O -framework AppKit`. Pass one word per invocation. Dictionary health probes run after timing to avoid prewarming; shared macOS service caches may still persist across processes. This does not measure end-to-end keyboard latency.

After 3.1.1, slash/@ boundary expectations explicitly preserve the preceding token to avoid changing address/path fragments. Tab is now a correction boundary. Model spelling calls the production spellingCorrection decision; technical boundaries use the production classifier policy. Approximate name substitutions are removed. Generated JSON is intentionally ignored by Git and regenerated by the script.
