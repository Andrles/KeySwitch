# Безопасность

## Поддерживаемая версия

Исправления безопасности выпускаются для последней версии KeySwitch.

## Сообщение об уязвимости

Не создавайте публичный issue для уязвимости, которая может раскрыть пользовательские данные или позволить выполнение кода. Используйте **Security → Report a vulnerability** в репозитории GitHub.

Укажите версию KeySwitch, версию macOS, шаги воспроизведения и возможное влияние. Не прикладывайте реальные пароли или приватный набранный текст.
