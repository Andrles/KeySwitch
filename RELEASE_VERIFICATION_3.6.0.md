# Проверка KeySwitch 3.6.0

22 ноября 2026 года. Версия 3.6.0, сборка 41, macOS 13+, universal arm64/x86_64.

## Проверено

- Полный набор `scripts/test.sh`: движок, орфография, словари, предпочтения неоднозначных пар, совместимость профилей, сохранение языка по приложению, безопасная замена суффикса и единственный экземпляр приложения.
- Предложение исключения после трёх отмен: до подтверждения слово не сохраняется; принятие сохраняет исключение, отказ действует до перезапуска, счётчики не переносятся в новый экземпляр настроек. Нативные кнопки принятия и отказа проверены в обеих темах, включая длинное слово и возврат обычной подсказки.
- Нативный интерфейс: 8 страниц, светлая/тёмная темы, минимальная ширина, 48 состояний панели, подсказки и действия словаря.
- Реальные переходы Finder/TextEdit и чтение источника ввода macOS через тестовый процесс с производственным обработчиком: девять сценариев. Клавиатура в этом тесте не перехватывается, настройки изолированы, текст не вводится.
- Исправлен воспроизведённый пропуск языка при запаздывании `frontmostApplication`. Один проход главной очереди допускается только без нового ввода и смены поколения активации; активное приложение и разрешённость проверяются повторно.
- Корпусы: 12 936 и 39 973 строки, каждый с системными словарями и без них. Дополнительно проходят 320 сценариев смешанных технических названий в каждом режиме; ни один ранее успешный случай не потерян. Это не слепой сравнительный тест и не число уникальных дефектов.
- Установочные сценарии на системном Bash: первая установка, обновление, отсутствующий/завершённый/работающий/неотвечающий процесс, отказ инвентаризации, чужая программа, символические ссылки, повреждённая новая копия. Тестируются изолированные копии и процессы.
- Терминальная установка: выбор текущего стабильного релиза через публичный redirect, версии 3.2.0/3.6.0, отказ загрузки, отказ установки, неверные адрес и тег. Проверки добавлены в обе сборки GitHub Actions.
- Конечные PKG и ZIP распакованы: полное совпадение файлов приложения с проверенной сборкой, версия 3.6.0/41, bundle ID, обе архитектуры, подпись и режим исполняемого файла. Встроенные сценарии совпадают с исходниками; место установки `/Applications`.
- Приложения из конечных PKG и ZIP отдельно прошли `--launch-check`: окно, панель, активация, закрытие, режим без Dock.

## Установка и ограничения

PKG заменяет `/Applications/KeySwitch.app`. Другие копии в `/Applications` удаляются только при совпадении bundle ID `local.keyswitch.app` и после проверки подписи новой копии. Чужие приложения, ссылки, пользовательские настройки и разрешения не удаляются.

Привилегированное обновление рабочего Mac не выполнялось; изолированные сценарии его не заменяют. Физический запуск на Intel и ввод клавиатурой новых вариантов в Safari/чате не проверены. Консервативные пропуски для неоднозначных слов и защищённых идентификаторов остаются.

Подпись приложения ad-hoc. Developer ID и нотариализации нет; после обновления macOS может запросить повторное разрешение Универсального доступа. Инструментарий Apple выдаёт прежнее предупреждение о x86_64 в `libswiftCompatibilityPacks.a`; конечные архитектуры проверены. Заявление о превосходстве над всеми конкурентами этими тестами не обосновано.

Артефакты и журналы проверки сохраняются локально в `build/release-3.6.0/`. История исследования конкурента и извлечённые бинарные материалы в релиз не включены.

При первой отправке GitHub отменил сборки до выполнения тестов: конфигурация macOS 14 больше не поддерживается. Оба workflow переведены на `macos-15` согласно [объявлению GitHub](https://github.blog/changelog/2026-10-01-github-actions-macos-14-runner-image-retirement/). Тег до публикации релиза передвинут на исправленную конфигурацию; исходники и проверенные установщики приложения не менялись.
