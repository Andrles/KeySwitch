# Проверка установки KeySwitch 3.3.1

5 октября 2026 года. macOS 26, Apple Silicon.

## Исправления

- Проверка пути установки выполняется до остановки работающего приложения.
- Ошибка получения списка процессов прерывает установку, а не считается отсутствием запущенных копий.
- Символические ссылки на папку назначения или основное приложение блокируют установку.
- Зависшая копия, не завершившаяся после SIGTERM, блокирует замену. Принудительное завершение не применяется.
- Дубликаты удаляются только после проверки исполняемого файла, идентификатора и подписи новой копии. При неудачной проверке старые дубликаты сохраняются.
- Удаление ограничено обычными `.app` в `/Applications` с идентификатором `local.keyswitch.app`. Настройки, посторонние приложения и символические ссылки не удаляются.

## Выполненные проверки

- Тесты языкового движка, профилей приложений, сокращений и ручных действий: прошли.
- Сборка для arm64 и x86_64: выполнена. Intel на реальном устройстве не проверялся.
- Запуск, создание окна, скрытие и повторное открытие через меню, переключение отображения в Dock: прошли диагностический сценарий.
- Изолированные сценарии установочных скриптов под системным `/bin/bash`: первая установка; отсутствие процессов; завершившийся процесс; остановка работающего процесса; зависшая копия; чужое приложение по пути назначения; символическая ссылка; ошибка списка процессов; отсутствующая или повреждённая новая копия; удаление дубликатов; сохранность чужих приложений и ссылок. Все прошли.
- Выбор загрузки: версионный и прежний PKG, отсутствие установщика, неправильный домен. Все прошли.
- Готовый PKG распакован: версия 3.3.1, сборка 35, arm64/x86_64, пути установки, встроенные скрипты и права root:wheel проверены. Подпись приложения проверена; байты файлов совпадают со сборкой.
- Настоящее обновление на Mac: 3.2.0 → 3.3.1 успешно. Старая работающая копия остановлена; пакет заменил основной bundle. Подготовленный дубликат старой версии удалён. Установленное приложение соответствует содержимому PKG и запускается.
- Пользовательские настройки до и после обновления совпадают. Изменилась только служебная дата последнего запуска.

## Ограничения

Настоящая первая установка на чистую macOS не выполнялась: этот сценарий проверен изолированными скриптами. Новая версия использует тестовую ad-hoc подпись, а не Developer ID и notarization. После обновления macOS потребовала обновить существующее разрешение Универсального доступа. После подтверждения Touch ID старая запись KeySwitch заменена записью установленной копии; приложение подтвердило «Доступ разрешён» и «Исправление включено». Простое выключение и включение старой записи с перезапуском не помогло. Для надёжного переноса доверия между выпусками нужна стабильная Apple Developer ID подпись.

Системный `pkgbuild` печатает четыре предупреждения `write: Permission denied` при стандартном назначении владельца root. Они воспроизведены и при упаковке пустой папки, и вне ограничений среды Codex. Упаковщик завершился успешно; реальные права, содержимое пакета и настоящая установка проверены. Переход на `--ownership preserve` убирает предупреждения, но назначает файлам UID разработчика; этот обход не используется.
