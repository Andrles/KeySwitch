# Участие в разработке

Спасибо за интерес к KeySwitch.

## Сообщение об ошибке

Перед созданием issue проверьте последнюю версию. Укажите:

- модель Mac и версию macOS;
- версию KeySwitch;
- приложение, в котором возникла ошибка;
- введённый текст и ожидаемый результат;
- наличие приложения в списке исключений;
- crash report, если приложение завершилось.

Не публикуйте пароли, персональные данные и большие фрагменты частной переписки.

## Pull request

1. Создайте отдельную ветку.
2. Внесите сфокусированное изменение.
3. Добавьте регрессионный тест для языкового движка.
4. Выполните `./scripts/test.sh` и `./scripts/build.sh`.
5. Опишите поведение до и после изменения.

Сохраняйте офлайн-модель обработки: введённый текст не должен передаваться внешним сервисам.
