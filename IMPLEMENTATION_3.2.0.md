# KeySwitch 3.2.0: реализация и проверка

Дата: 4 октября 2026. Основание: COMPARISON_AUDIT_2026-10-04.md. Локальные PKG и ZIP версии 3.2.0 созданы после проверок и проверены после распаковки. Установленная версия 3.1.1 сохранена; проверенная новая сборка запускалась отдельно.

## Реализовано

- P1: установка выбирает реальный PKG из GitHub Release; отсутствие пакета и посторонний адрес блокируются до запуска установщика.
- P1: список исключений сохраняет добавления из подсказки, даже если настройки уже открыты.
- P2: монитор и меню используют точное совпадение идентификатора исключённого приложения.
- P2: понятные названия разделов и пунктов меню, разные состояния значка, системный цвет акцента, описание режима обновляется без перестройки секции.
- P2: отдельные ручные действия, настраиваемые сочетания и режим «Двойной Shift — только раскладка». Контекст сохраняется при взаимодействии с меню; применение повторно проверяет внешний редактор.
- Развитие: смена раскладки и регистра выделения через AXSelectedText; отсутствуют вставка через буфер обмена и удаление клавиатурными событиями.
- Развитие: правильные слова и явные пары исправлений, экспорт/импорт JSON с ограничением размера и объединением записей. Исключения имеют приоритет.
- При ревью устранены потеря контекста при открытии меню, потеря неверного черновика словаря и ненормализованный импорт слов. Неверная пара блокирует переход, экспорт и скрытие окна.
- После физической проверки обнаружены управляющие символы рядом с результатом ручных команд. Исправлен опасный отказ: назначенное сочетание теперь подавляется и при неуспехе операции. AX-запись выполняется после выхода из обработчика клавиш; новый ввод, клик, прокрутка, смена приложения или источника ввода отменяют запоздавшую команду. Повторная физическая проверка подтвердила чистый результат трёх преобразований.

## Проверено

- Регрессионные тесты языкового движка, пользовательского словаря, сохранности исключений, сочетаний и преобразования выделения: прошли.
- Отдельный запуск с системным словарём macOS: прошёл.
- Расширенный корпус: 12 936 сценариев для каждого словарного режима. Проверки сохранности правильного текста, орфографии, потока, длинного ввода и обратимости прошли. Из 1658 случаев автоматической раскладки ожидаемый результат получен в 1466 с локальным словарём и 1594 с системным: осторожные пропуски сохраняются.
- Скрипты установки под macOS Bash 3.2: первая установка, обновление, работающие/завершившиеся процессы, дубликаты, чужие приложения и символические ссылки — прошли изолированные fixtures.
- Выбор загрузки: версионный и стабильный PKG, отсутствие PKG, неверный адрес — прошли. Проверки включены в общий тест установщика и CI.
- Универсальная сборка arm64/x86_64 выполнена. Предупреждение CLT о compatibility library не препятствует линковке, но не заменяет проверку Intel runtime.
- Диагностический запуск: окно, скрытие/повторное открытие и режим без Dock прошли. Диагностика выключает глобальный ввод и сеть.
- Живой UI preview 3.2.0: словарь и новые настройки отображаются; неверная пара вызывает явную ошибку и остаётся в поле. Повторная проверка подтвердила сохранность черновика и единственный выбранный раздел sidebar. Финальная компоновка с описанием внутри карточки режима и новая иконка проверены визуально.

- Живой импорт/экспорт через системные диалоги: проверен JSON со словами и исключениями с внешними пробелами; экспорт содержит нормализованные слова и сохраняет регистр явной замены.
- Подпись bundle и совпадение контрольных сумм сборки с актуальными исходниками: подтверждены. Подпись ad-hoc, Developer ID и notarization отсутствуют.

## Живая проверка и готовый пакет

Разрешение для актуальной ad-hoc сборки включено; обычный запуск приложения подтверждает готовность монитора. В macOS 27 категория разрешения называется «Управление устройством и доступ к данным». Запуск исполняемого файла из диагностической оболочки не дал того же результата, поэтому живые проверки выполняются через обычный запуск bundle.

Первая физическая проверка в TextEdit обнаружила дополнительные управляющие символы. После исправления пользователь физическими клавишами проверил «Ghbdtn, vbh!» → «Привет, мир!» → «ПРИВЕТ, МИР!» → «привет, мир!» и подтвердил все три чистых результата. AX-снимок TextEdit дополнительно подтвердил конечное значение «привет, мир!» без служебных символов. Автоматическая отправка этих сочетаний через средство управления UI остаётся непригодной для подтверждения глобального перехвата: она вставляла служебный символ. Временные сочетания теста возвращены к исходному значению «Без сочетания».

После успешной физической проверки повторно прошли регрессии. PKG и ZIP распакованы: версия 3.2.0, сборка 32, arm64/x86_64, путь установки /Applications, строгая подпись bundle и исполняемые права подтверждены. Исполняемый файл обоих архивов побайтово совпадает с проверенной сборкой; скрипты PKG совпадают с протестированными исходниками. Диагностический запуск распакованного PKG подтвердил окно, скрытие/открытие и переключение Dock. Сообщения «write: Permission denied» при упаковке не привели к повреждению этих проверенных payload; упаковка и распаковка завершились успешно.

SHA-256 локального ZIP: `017db30362a9a35eb19de7ff7df7f1dac8dd11fcbbe3d4fbe52343b068918a7e`.

## Публикация

GitHub Release v3.2.0 опубликован. Исправлен порядок CI: проверки установщика требуют готовый подписанный bundle, поэтому выполняются после сборки и до упаковки. Полный Build прошёл на GitHub.

Создание тега также запустило прежний release workflow, который успешно собрал приложение, но заменил проверенные локальные файлы другими бинарными сборками. Эти файлы сохранены под префиксом CI-; основные PKG и ZIP восстановлены из локально проверенных архивов. SHA-256 основных файлов повторно сверены с GitHub и совпадают с указанными выше. Автоматический установщик пропускает имена CI- и выбирает основной PKG.

Для будущих тегов release workflow изменён: создаёт черновик и не перезаписывает существующие одноимённые файлы. Это не изменяет уже выпущенный исполняемый файл. Поддерживаемые параметры draft и overwrite_files проверены по официальному action.yml softprops/action-gh-release v2.

## Остающиеся ограничения и следующий этап

Полный тест установки на живую систему, Intel runtime, VoiceOver и совместимость нескольких редакторов не выполнены. Производительность глобального обработчика в медленном AX-поле не измерена; время корпуса движка не является такой проверкой. Иконка приложения упрощена до одной языковой клавиши; символы строки меню различают состояния. Голос, AI и Windows/Linux остаются будущими дополнениями.

Проверки отказа при смене поля и защищённом вводе выполнены по коду и политикам; отдельный живой стресс-тест гонок фокуса и защищённых полей ещё не выполнен. Следующий этап: расширить совместимость редакторов и проверить подписанный Developer ID выпуск с обновлением без повторной авторизации.
