## Critique

Специфика поведения сильнее визуальной: RU/EN, исключение активного приложения и локальная обработка соответствуют продукту. Градиент, карточки и демонстрация Liquid Glass дают общий образ современной утилиты. Предлагаемое направление: готовность → понятное вмешательство → безопасное восстановление. Сохранить нативность; косметическая смена цветов не решает главный разрыв доверия.

| Эвристика Nielsen | /4 | Главный вывод |
|---|---:|---|
| Видимость состояния | 1 | Активность зависит от настройки, не готовности |
| Понятный язык | 3 | В основном ясно; технические пояснения лишние |
| Контроль и свобода | 2 | Пауза есть, восстановления исправления нет |
| Последовательность | 2 | Разные правила сохранения, устаревающие состояния |
| Предотвращение ошибок | 2 | Нет безопасного теста перед вмешательством |
| Узнавание вместо памяти | 2 | Двойной Shift скрыт в документации |
| Эффективность | 3 | Пассивная работа и исключения удобны |
| Минимализм | 3 | Группировка хорошая, декор занимает место |
| Восстановление ошибок | 2 | Нет пути исправить ошибочное решение приложения |
| Помощь | 2 | README несёт основную нагрузку |
| **Итого** | **22/40** | Существенные улучшения нужны |

Когнитивная нагрузка умеренная: 3 из 8 пунктов checklist требуют внимания. Шесть разделов и семь действий меню превосходят порог skill для одновременного выбора; этот порог — эвристика, не доказательство неудобства. Главное — перенос контекста между разрешением, внешним редактором и подсказкой на 2,4 секунды. Группировка, иерархия, последовательное раскрытие и короткие выборы режимов работают.

Эмоциональный путь: понятные примеры и приватность → сомнение при запросе разрешения → удовлетворение после исправления → потеря доверия при ошибочной замене без восстановления.

Персоны:
- Новичок Jordan: «активна» без доступного перехвата; нет проверки первого успеха.
- Опытный Alex: полезные исключения, но фиксированный и невидимый в приложении shortcut; нет быстрой команды восстановления.
- Пользователь VoiceOver Sam: безымянные переключатели, визуальное выделение навигации и исчезающая подсказка. Это риски по реализации; реальный VoiceOver не проверен.

Сохранить: исключение активного приложения с его именем/иконкой; понятное объяснение разрешения и локальной обработки; нативные меню, таблицы, segmented controls, системные цвета и материалы.

### P1: до следующего расширения

1. **Буфер не привязан к месту ввода.** KeyboardMonitor.swift:33,93,105,109,158; AppDelegate.swift:157; KeyboardReplacementPlan.swift:13. Смена приложения/фокуса мышью не очищает накопленное слово. Старое слово может вызвать backspace в новом поле. Последствия не воспроизводились live; отсутствие защиты подтверждено кодом. Связать операцию с приложением/полем/позицией, сбрасывать контекст, проверять возможность безопасной замены, иначе пропускать. Добавить восстановление только пока контекст подтверждён. **harden**.
2. **Валидное слово превращается в имя.** LanguageEngine.swift:306,359; Preferences.swift:69; KeyboardMonitor.swift:122. Нормализация имени идёт до проверки валидности. По алгоритму many → mary, хотя many есть во встроенном словаре; автоисправление включено по умолчанию. Сохранять валидные слова, пересмотреть уверенность и режим исправления имён. Это вывод по алгоритму, не новый тест. **harden**.
3. **Рекурсивный повтор запуска перехвата.** KeyboardMonitor.swift:48; AppDelegate.swift:51,198. При trusted=true и tapCreate=nil callback синхронно повторно вызывает start(). Устойчивый отказ может исчерпать стек. Разделить разрешение и операционное состояние, ограничить отложенные повторы, дать действие восстановления. **harden**.
4. **Безымянные switches и визуальное выделение sidebar.** SettingsWindowController.swift:118,337,415,827,910. Добавить программные имена, состояния выбора и проверить VoiceOver/клавиатуру; нативные роли уже существуют. **harden**.
5. **Ложное или устаревшее «активна/готово».** SettingsWindowController.swift:404,581,594,870,1149; AppDelegate.swift:143,231. Учитывать enabled, trusted, running и исключения; обновлять главное окно и меню единым состоянием. Заголовок/кнопка разрешений не обновляются полноценно. **clarify + harden**.

### P2: следующий проход

6. **Подсказка недоступна после 2,4 секунды.** SpellingIndicator.swift:17,44,63. Она не принимает мышь, не предлагает принятие/отклонение, не объявляет изменение через accessibility. Сделать управляемый доступный сценарий; не заменять текст, если контекст уже изменился. **harden**.
7. **Непредсказуемый объём работы в перехвате.** KeyboardMonitor.swift:53,105,109,120; SystemDictionary.swift:48,58,68,73,104; LanguageEngine.swift:364. Синхронные проверки, перебор расстояний до имён, неограниченный token и отрицательный cache. Ограничить token и все caches, измерить задержки, сохранить порядок событий и требования потоков AppKit. Реальные задержки не измерены. **optimize**.
8. **Неясное сохранение игнорируемых слов.** SettingsWindowController.swift:345,511,515,1024. Сохранение через action поля, без явного контракта при переходе. Принять единый способ commit и показать результат; проверить завершение редактирования. **harden + clarify**.
9. **Жёсткая геометрия.** SettingsWindowController.swift:220,259,790,806. Минимальное окно 900×620, sidebar 220, card ≥580 и фиксированные высоты. При указанном минимуме требования по ширине конкурируют. Использовать контентные высоты/компактную компоновку, проверить длинный текст и малую рабочую область. Визуальное обрезание не подтверждено. **adapt + layout**.
10. **Абсолютное «слова не сохраняются».** SettingsWindowController.swift:614; AppDelegate.swift:254; Preferences.swift:102. Введённые пользователем исключения сохраняются локально. Уточнить: нет истории печати; настройки и явно добавленные слова сохраняются. Не заявлять утечку: отправки текста в сеть не найдено. **clarify**.
11. **Неудачная проверка обновлений откладывает retry на сутки.** UpdateChecker.swift:86,118,120. Разделить успешную проверку и попытку, добавить короткий ограниченный backoff. Ручной retry есть. **harden**.

### P3

12. **Вращение иконки без Reduce Motion.** AppDelegate.swift:263,268,276. При системной настройке уменьшения движения сменять glyph без вращения. **animate**.

Дополнительно: убрать разговор о визуальном материале из основного сценария; объяснить двойной Shift в приложении; для пустых исключений дать понятный старт, выключить Remove без выбора. Малый вторичный текст и градиент проверить визуально, не считать заранее провалом контраста. Rich-text проблема из docs/KNOWN_ISSUES.md не подтверждена как дефект KeySwitch: воспроизвести с приложением и без него перед исправлением.

Команды impeccable направляют UX и качество; голос, AI и поддержка ОС требуют отдельной инженерной реализации. Порядок macOS → Windows → Linux — рекомендация для обсуждения, не утверждённое требование. Текущий LanguageEngine содержит связь с AppKit-словарём, поэтому даже перенос логики требует выделения интерфейса словаря. Не менять стек всего продукта до выбора платформенных ограничений.

Перед облачным AI изменить обещание приватности явно: локальные функции сохраняют локальную обработку; выбранный текст отправляется только по осознанному действию. Не копировать цены, рекламные цифры или функциональные обещания Keyray в KeySwitch.

После согласования: применить этапы 1–3 к текущему приложению, провести содержательные регрессии и одну визуальную проверку с одним подтверждающим проходом после исправлений. Финальный polish закрывает этот объём. Голос/AI/другие ОС идут следующими вертикальными этапами с отдельными критериями готовности; текущий polish не означает достижение полного паритета.
