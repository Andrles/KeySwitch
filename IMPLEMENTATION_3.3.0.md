# KeySwitch 3.3.0 — локальная проверочная сборка

5 октября 2026. Сборка 34. Дополняет изменения 3.2.1; установленная копия, разрешения macOS и опубликованный релиз не заменялись.

## Реализовано

- Профили приложений: автоматическая смена раскладки, проверка орфографии и сокращения управляются отдельно. Профили сохраняются локально. Частичный профиль не блокирует ручные команды; прежнее полное исключение блокирует их тоже. Меню полного исключения сохраняет профиль, который восстановится после снятия блокировки. Повторный выбор уже добавленного приложения не сбрасывает профиль.
- Сокращение в готовую фразу: отдельное включение в «Моём словаре», явное сохранение, запуск только после одного пробела. Enter, Tab и пунктуация не запускают разворачивание. Игнорируемые слова имеют приоритет. Текущая раскладка сохраняется; регистр готовой фразы берётся из правила.
- Ограничения: сокращение — одно слово до 64 символов; фраза — одна строка до 256 символов и 512 единиц UTF-16, без управляющих символов. Ввод разбивается на ограниченные части с сохранением целых графем; слишком длинная отдельная графема отклоняется. Все события подготавливаются перед удалением исходного текста.
- Замена и её отмена используют существующие проверки поля, курсора, исходного текста и времени. Отмена доступна до нового ввода, смены контекста или 15 секунд. При режиме двойного Shift «только раскладка» отмена выполняется ручной командой.
- Фразы включены в JSON-перенос словаря. Новая версия читает старые файлы. Нормализованные дубликаты отклоняются до слияния; импорт сохраняет текущие записи и явно сообщает о замене совпадающих ключей. Старые версии не поддерживают новую категорию фраз.
- Polish: отдельные подписи «Сокращение»/«Готовая фраза», примеры, подсказки по выбранному типу, сохранение черновика при ошибке, явное сообщение о выключенной функции. Нового раздела навигации не добавлено.

## Проверено

- Fallback и настоящий системный словарь macOS: все компонентные regression checks проходят, включая профили, сохранение, приоритет исключений, границы запуска, ограничения фраз, Unicode, JSON legacy/roundtrip и коллизии при слиянии.
- Полный корпус 12 936 случаев. System: keep 4346/4346, exploratory keep 3000/3000, spelling 728/728, stream 141/141, roundtrip 3000/3000, layout 1594/1658. Fallback layout 1466/1658. Прежние пропуски распознавания остаются; эти показатели не означают, что все случаи проходят. Ядро LanguageEngine в этом этапе не менялось.
- Universal build arm64/x86_64, строгая проверка ad-hoc подписи и совпадение source manifest проходят. Известные предупреждения местного toolchain об отсутствующей x86_64 в compatibility archive остаются; Intel runtime не проверен.
- Изолированный запуск: окно создано и видно, hide/reopen и переключение Dock/menu-bar presentation проходят. Это проверка запуска без глобального мониторинга.
- Реальный UI preview: выбор Xcode, включение только орфографии с сохранением выбранной строки; сохранение `спс → Спасибо, хорошего дня!`; отдельное включение сокращений; ошибка для фразы из 257 символов без потери черновика. После polish на конечной сборке повторно подтверждены подписи, подсказки и сохранение фразы. Снимки: `build/polish-3.3.0/`.
- Установочные fixtures и `git diff --check` проходят. Во время preview зафиксировано предупреждение macOS `Window move completed without beginning`; оно не сопровождалось отказом сохранения. Preview остановлены.

## Что остаётся до выпуска

Глобальная замена фразы, отмена и фактическое поведение профилей во внешних редакторах на 3.3.0 ещё не подтверждены. Компонентные тесты и UI preview этого не доказывают. Полный VoiceOver, минимальный размер окна, Intel runtime/macOS 13 и многомониторность также не подтверждены.

Установщик не создавался. Навык release-check требует: “Do not create an installer while relevant tests fail, a reproduced defect remains, or an essential check cannot be completed.” Основной внешний сценарий относится к обязательной проверке перед упаковкой.

Следующий живой прогон на единственной запущенной, разрешённой macOS копии 3.3.0:

1. В обычном тестовом документе: `спс` + пробел → `Спасибо, хорошего дня! `; раскладка прежняя.
2. Ручная отмена сразу после замены → `спс `; повторная отмена или отмена после нового ввода не меняет посторонний текст.
3. `спс` + Enter/Tab/пунктуация остаётся сокращением; выключенная функция и профиль без сокращений тоже не разворачивают его.
4. При профиле «только орфография» автоматическая раскладка не меняется, а ручная смена раскладки остаётся доступной. При полном исключении ручная команда объясняет отказ.
5. Проверить обычный текст с кириллицей, латиницей, пунктуацией и emoji; затем смену поля, выделение, защищённое поле и новое нажатие до отмены.

AI, голос и другие ОС остаются будущими глобальными дополнениями. Капитализация и списки — следующие отдельные пункты плана.

## Живой прогон — продолжение 5 октября

Добавлен `--runtime-check`: отдельный профиль настроек, выключенные обновления и звук, два тестовых сокращения (`spas`, `sig`), отмена Control+Option+Z и смена раскладки Control+Option+L. Диагностический перехват пропускает все приложения, кроме TextEdit, включая их ручные сочетания. Обычный запуск этой настройкой не меняется.

Новая конечная сборка с диагностикой собрана и подписана; компонентные тесты повторно проходят. Старая запущенная 3.2.0 временно завершена, её bundle и обычные настройки не заменены. На 3.3.0 подтверждено `trusted=true running=true target=TextEdit isolatedPreferences=true`: доступ и запуск настоящего event tap работают. TCC не сбрасывался и новый доступ вручную не выдавался.

Создан отдельный тестовый документ TextEdit. Автоматическое нажатие клавиш дало `Spas ` и `test spas ` без разворачивания. TextEdit меняет первую букву в начале строки; точная причина отказа в варианте внутри строки ещё не установлена. Этот прогон не подтверждает основную замену и не позволяет объявить дефект устранённым. Отправлен запрос на физический ввод сокращения и немедленную отмену без управления окном со стороны Codex. До ответа результат основного сценария остаётся неподтверждённым; установщик не создаётся.

Следующая автоматическая проверка ручной смены выделения (`Ghbdtn, vbh!`, Control+Option+L) вставила U+000C вместо ожидаемой фразы. Это зарегистрированный неуспешный прогон; источник различия между автоматическими и физическими клавишами ещё не установлен. Исходный тестовый текст восстановлен и выделен. Пользователю отправлен запрос на физическое нажатие этой команды. До ответа ручная смена раскладки на конечной 3.3.0 остаётся неподтверждённой. Установщик не создавался.

### Итог живого прогона и упаковки

Пользователь подтвердил физическую ручную команду: `Ghbdtn, vbh!` → `Привет, мир!`. Неподтверждённый автоматический прогон не считается воспроизведением отказа при физическом вводе. Живые сокращение/возврат сокращения и ручная смена выделения на этой сборке подтверждены; профили и ограничение разделителей проверены компонентными тестами и UI, без отдельного полного физического прогона всех сочетаний.

Тестовый режим остановлен. Обычная установленная 3.2.0 вновь запущена и показывает «Исправление включено». Установленный bundle не заменён, пользовательские настройки сохранены.

Созданы окончательные локальные `build/KeySwitch-3.3.0.pkg` и `build/KeySwitch-3.3.0.zip`. Проверка извлечения: версия 3.3.0/build 34, путь /Applications, strict bundle identifier local.keyswitch.app, universal arm64/x86_64. Каждый файл приложения в обоих артефактах побайтно совпадает с проверенным build/KeySwitch.app; embedded preinstall/postinstall совпадают с проверенными сценариями и имеют право исполнения. Строгая проверка подписи обоих извлечённых bundle проходит. Приложение из окончательного PKG прошло --launch-check: окно, hide/reopen и Dock/menu-bar presentation.
