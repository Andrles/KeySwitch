# Политика приватности KeySwitch

Дата обновления: 31 июля 2026 года.

KeySwitch обрабатывает клавиатурный ввод локально на устройстве пользователя исключительно для определения языка, исправления раскладки и проверки орфографии.

## Какие данные обрабатываются

- текущее набираемое слово;
- идентификатор активного приложения для применения списка исключений;
- локальные настройки KeySwitch и счётчик исправлений.

## Что KeySwitch не делает

- не передаёт введённый текст через интернет;
- не хранит историю набранного текста;
- не использует аналитику, рекламу и сторонние трекеры;
- не продаёт и не передаёт пользовательские данные.

Слова проверяются встроенным языковым движком и системными словарями macOS. Разрешение «Универсальный доступ» используется для глобального чтения клавиатурных событий и выполнения исправлений.

## Проверка обновлений

По желанию пользователя KeySwitch обращается к публичному API GitHub, чтобы
узнать номер последнего релиза и получить ссылку на установочный пакет.
Автоматическую ежедневную проверку можно отключить в настройках. В запрос не
включаются введённые слова, история ввода или содержимое документов.
