# KeySwitch 3.4.0 — локальная установочная сборка

17 октября 2026 года. Версия 3.4.0, сборка 37. GitHub на этом этапе не обновлялся.

## Готовые файлы

- `build/KeySwitch-3.4.0.pkg` — установка в /Applications с заменой основной копии и удалением проверенных дублей KeySwitch в этой папке.
- `build/KeySwitch-3.4.0.zip` — приложение без установочных сценариев очистки.
- `build/KeySwitch-3.4.0.sha256` — контрольные суммы.

## Проверки

- Основные регрессии прошли в двух режимах: с системным словарём macOS и с резервным словарём.
- UI-проверки прошли: 8 страниц в двух темах при минимальной ширине, нативные переключатели, непрозрачный фон доступности, длинные слова, действия подсказки, выбор записи словаря.
- Физический ввод подтверждён пользователем на том же коде приложения до обновления номера версии: слова, имя, длинное слово, следующая буква после исправления, запятая, двойной Shift и отмена, кнопки подсказки, отмена исключения и переход в поиск TextEdit. Подробности: RUNTIME_VALIDATION_2026-10-17.md.
- Установочные сценарии прошли изолированные проверки первой установки, обновления, работающих/завершившихся/зависших процессов, защиты постороннего приложения и символьных ссылок. Настройки и разрешения сценарии не сбрасывают.
- Финальные PKG и ZIP распакованы. Все файлы приложения побайтно совпадают с собранным bundle. Подтверждены версия 3.4.0, build 37, идентификатор, arm64/x86_64 и подпись приложения. Скрипты совпадают с исходными и имеют исполняемые права; путь установки /Applications, перемещение по найденной копии отключено, используется upgrade.
- BOM: владелец root, отсутствуют доступные всем на запись файлы и каталоги.
- Проверка запуска приложения из финального PKG прошла: окно создаётся, скрывается и повторно открывается; проверены режим строки меню и переключение Dock. Проверка запуска отключает глобальную обработку ввода.

## Ограничения

- Приложение подписано ad-hoc. PKG не подписан Developer ID и не нотариализован. После обновления macOS может потребовать повторно разрешить универсальный доступ.
- Полное обновление рабочего Mac и сохранение его разрешения Accessibility не проверены. Изолированные сценарии и распаковка не заменяют такую проверку. Установленная копия в этом этапе не заменялась.
- pkgbuild завершился успешно, но вывел четыре предупреждения `write: Permission denied`, воспроизводимые и вне ограниченного запуска. Предупреждения возникают на этапе pkgbuild; их точная причина не установлена. Повреждения содержимого не обнаружены: файлы, права, метаданные версии, скрипты и запуск извлечённого приложения проверены отдельно. Успешная установка пакета на рабочей системе этим не подтверждена.
- Среда сборки предупреждает об отсутствии x86_64 в libswiftCompatibilityPacks.a. Универсальный бинарный файл собран; запуск на Intel Mac не проверен.
- Сложный языковой корпус содержит описанные ранее неоднозначности и пропуски. Релиз не означает устранение всех возможных ошибок; см. CARAMBA_FIXES_2026-10-16.md.
